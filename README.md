## Snow-free LAI Generation Workflow

The following files are used in the generation of the snow-free LAI dataset. Their functions are described below:

### Script Descriptions

1. **`createLifespanPFT.py`**
   Generate PFT-level leaf lifespan data

2. **`merge_LUT.py`**
   Merge TRY lookup table (LUT) data

3. **`mksnowfreeLAI.F90`**
   Generate snow-free LAI

4. **`process_lifespan.py`**
   Perform quality control on lifespan data

5. **`export.r`**
   Export lifespan, PFT, and growth form data from TXT to CSV format

6. **`merge_growthform.py`**
   Merge TRY growth form data

7. **`merge_pft.py`**
   Merge TRY PFT data

8. **`process_growthform.py`**
   Process TRY growth form data
